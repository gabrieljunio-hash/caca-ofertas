# Caça Ofertas

Painel inicial para organizar promoções e gerar textos prontos para compartilhar no WhatsApp.

## O que funciona nesta versão
- Cadastro manual de ofertas do Mercado Livre, Shopee ou outras lojas.
- Filtros por loja, categoria e nome do produto.
- Cálculo de desconto com base nos preços informados.
- Geração e cópia de texto de anúncio com link de afiliado.
- Armazenamento local no navegador do dispositivo.

## Ainda não implementado
- Busca automática contínua.
- Integração com APIs oficiais do Mercado Livre e da Shopee.
- Verificação automática de preço/estoque e geração de links afiliados.
- Publicação automática no WhatsApp.

Os produtos de exemplo não são ofertas reais. Para habilitar a pesquisa contínua, precisamos validar o acesso às APIs/programas de afiliados e executar a rotina em um serviço online, sem expor tokens no navegador.

## Como publicar gratuitamente
Ative GitHub Pages em **Settings → Pages → Deploy from a branch → main → /(root)**. Depois acesse o endereço Pages que o GitHub informar.
